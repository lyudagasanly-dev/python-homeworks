БАГ-РЕПОРТ ПО РЕЗУЛЬТАТАМ ТЕСТИРОВАНИЯ КЛАССА STRINGUTILS

ID: BUG-01
Название: Метод contains() возвращает неверное логическое значение при поиске существующего символа
Компонент: string_utils.py / Метод contains
Серьезность: Critical (Критическая, так как ломает основную логику метода)

Описание: 
При вызове метода contains() для проверки наличия существующего в строке символа, метод возвращает False вместо True. Ошибка обнаружена автоматическим тестом `test_contains[SkyPro-True]`.

Шаги воспроизведения:
1. Создать объект класса StringUtils: utils = StringUtils()
2. Вызвать метод contains со следующими параметрами: utils.contains("SkyPro", "P")

Ожидаемый результат: 
Метод должен вернуть значение True (так как символ 'P' присутствует в строке 'SkyPro').

Фактический результат: 
Метод возвращает False, тест падает с ошибкой AssertionError: assert True == False.
